 Objective
To segment mall customers based on purchasing behavior and design targeted marketing strategies using unsupervised learning.

 Approach
- Data preprocessing and scaling
- Exploratory Data Analysis (EDA)
- K-Means clustering model
- PCA for visualization
- Marketing strategy generation

 Results
- 5 distinct customer segments identified
- Clear behavioral patterns observed
- Actionable marketing strategies created for each cluster

 Tools Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

 Key Insight
Customer income does not directly determine spending behavior, enabling businesses to refine targeting strategies.
